# Раскладка окна

Карта — основная сцена. Частые команды сидят на узком тулбаре слева, редкие правила — в диалоге «Настройки боя», справочные списки — в прячущейся панели справа. Отдельной страницы «Настройка армий» больше нет: шаблоны отрядов живут в немодальном окне «Стороны», а существо правится карточкой с карты и из списка участников.

Видимость и размеры панелей пишет `QSettings` (`Renegats` / `DnDBattleSimulator`): геометрия окна, `saveState` тулбара и дока, номер вкладки панели, геометрия «Настроек боя» и окна «Стороны». При запуске с `QT_QPA_PLATFORM=offscreen` (тесты) используется отдельное имя `DnDBattleSimulator.test`, чтобы прогон не затирал раскладку пользователя.

## Что взято у VTT и трекеров

Смотрел на типичную раскладку Foundry VTT, Owlbear Rodeo, Roll20, D&D Beyond Encounters и Improved Initiative. В код ушло следующее.

| Приём | Откуда | Как у нас |
|---|---|---|
| Карта занимает почти всё окно, хром тонкий | Owlbear, Foundry, Roll20 | Центральный виджет — карта. Журнал под картой убран: он живёт в панели |
| Вертикальная полоска иконок без подписей, смысл в подсказке | Левая рейка Owlbear, инструменты сцены Foundry | Тулбар: стороны, создать, раунд, автобой, пауза, отмена, повтор, настройки, тема |
| Сайдбар с вкладками-иконками, его можно закрыть | Foundry (чат, трекер, актёры, журналы), правая колонка Roll20 | `QDockWidget` «Панель боя»: Участники, Журнал, Бестиарий. Вкладки справа, с иконкой и текстом |
| Порядок хода отдельным коротким списком, а не простынёй кнопок | Improved Initiative, combat tracker Foundry, колонка инициативы D&D Beyond | Над участниками — инициатива последнего раунда. Двойной щелчок центрирует токен |
| Правила и «показывать ли хиты» не висят на карте | Настройки Improved Initiative и Foundry, а не холст | Диалог «Настройки боя»: крит, автоперемещение, скрытие хитов, ручной режим, вид карты, фон, альянсы. Секции сворачиваются |
| Полоса действий появляется только когда ход нужно решить руками | Панель хода D&D Beyond Encounters | `manual_bar` под картой по-прежнему скрыта, пока идёт ручной ход |

Не копировались нижний хотбар макросов Foundry и отдельный «театр» Roll20: в симуляторе нет макросов, а сцена одна.

## Иконки

Значки тулбара и вкладок рисуются в `qt_icons.py` (круг, треугольник, дуга, шестерёнка). Отдельных SVG нет и чужой лицензии нет: это рисунки проекта, цвет берётся из палитры `qt_theme`, поэтому они читаются и на графите, и на пергаменте. Кнопка темы по-прежнему векторная `IconButton` (луна / солнце) из `qt_widgets.py`.

## Редактор на карте

Страница армий убрана из стека: в центре одна карта. `CardsHost` лежит в немодальном окне «Стороны» (`sides_dialog`). Иконка тулбара и пункты «Бой / Вид → Стороны…» вызывают `show()`.

Существо правится немодальной карточкой `CreatureSheet` (`qt_creature_sheet.py`). Её открывают «Карточка существа» в контекстном меню, двойной щелчок по строке участника и «Массовое редактирование». Секции «Атаки» и «Состояния» сразу развёрнуты, характеристики и защиты — внутри своего блока и свёрнуты, пока не нужны. «Применить» пишет поля и кладёт один шаг в ту же историю, что ход и раунд. «Закрыть» ничего не записывает.

Правый щелчок по пустой клетке (не во время ручного хода и не во время прицеливания области) открывает «Добавить существо сюда…». То же действие есть в меню «Бой» и под списком участников. Импорт из вкладки «Бестиарий» после регистрации типа открывает этот диалог.

Крит по умолчанию по-прежнему `double_all`: удваивается весь урон, вместе с модификатором. Дополнительный бонус инициативы по умолчанию 0, поэтому бросок без него — по-прежнему d20 + мод Ловкости.

### Где было во вкладке армий → где теперь

| Было во вкладке армий | Где теперь |
|---|---|
| Страница «Настройка армий» на всё окно | Окно «Стороны»: иконка тулбара, «Бой → Стороны…», «Вид → Стороны…» |
| Карточка отряда: имя, состав, тактика, количество | Те же поля в окне «Стороны» |
| Портрет: другая картинка и поиск на dnd.su | Те же кнопки на карточке отряда в окне «Стороны» |
| Удалить отряд, плюс «добавить сторону» | Карточка отряда; ещё «Бой → Добавить сторону» |
| «Изменить состав»: бестиарий или своё существо | Карточка отряда. Плюс «Из бестиария…» / «Своё существо…» при добавлении одного существа на карту |
| «Создать армии» | Тулбар, «Бой → Создать армии», кнопка внизу окна «Стороны» |
| Правка уже созданного существа (имя, хиты, КД, скорость, регенерация, атаки, характеристики, сопротивления, состояния) | Карточка существа: правый щелчок по токену или по строке «Участники», двойной щелчок по строке |
| Сторона существа отдельно не менялась | Карточка и пункт «Сменить сторону» (в том числе «Новая сторона…») |
| Инициатива только броском d20 + Ловкость | То же по умолчанию. В карточке есть дополнительный бонус, с нуля он бросок не меняет |
| Одно существо на конкретную клетку | Правый щелчок по пустой клетке «Добавить существо сюда…», «Бой → Добавить существо…», кнопка под списком участников |
| Дублировать / удалить существо с подтверждением | Пункты контекстного меню токена и строки участника |
| Перетащить токен или кликнуть клетку в пределах скорости | Как раньше. «Переместить» в меню ставит на любую свободную клетку и скорость не тратит; Esc отменяет ожидание клетки |
| Сохранить / загрузить армии | «Файл → Сохранить настройки» / «Загрузить настройки» (шаблоны, свои типы и снимок боя) |
| Очистить расставленных, не трогая шаблоны | «Бой → Очистить поле» (с подтверждением, отменяется) |
| Массовая правка отмеченных галочками | Кнопка под списком участников и «Бой → Массовое редактирование» — та же карточка |

Правка через карточку, дубль, удаление, смена стороны, перемещение мастером, добавление существа, очистка поля и прежние действия отряда (добавить сторону, сменить состав, число, имя, «Создать армии») пишутся в undo/redo.

Особые действия статблока (дыхание, легендарные, бонусные, реакции) на карточке видны списком имён. Их сценарий карточка не переписывает: при «Применить» он остаётся на существе, как пришёл из пресета или бестиария. Число существ в шаблоне и портрет по-прежнему свойства отряда, не токена. «Создать армии» по-прежнему заменяет текущий состав поля шаблонами.
